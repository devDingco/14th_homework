핵심요구사항) 여행상품 상세 페이지의 Mock데이터를 제거하고, GraphQL API를 통해 실제 데이터를 바인딩할 것.
            1) 바인딩할 데이터
                - GraphQL fetchTravelproduct 쿼리를 사용하여 여행상품 상세 조회
                - @tanstack/react-query를 사용하여 데이터 페칭 처리
                - URL 파라미터에서 _id를 추출하여 쿼리 파라미터로 전달
            
            2) 상세내용
                - Title Area (제목 영역)
                    - 제목: Travelproduct의 name
                    - 부제목: Travelproduct의 remarks
                    - 해시태그: Travelproduct의 tags 배열을 "#" 접두사와 함께 표시
                    - 북마크 수: Travelproduct의 pickedCount
                
                - Purchase Area (구매 영역)
                    - 메인 이미지: Travelproduct의 images 배열 첫 번째 이미지
                    - 썸네일 이미지: Travelproduct의 images 배열 나머지 이미지들
                    - 가격: Travelproduct의 price (천 단위 콤마 표시)
                    - 판매자 정보: Travelproduct의 seller 정보
                
                - Content Area (상세 설명 영역)
                    - 상세 설명: Travelproduct의 contents
                
                - Map Area (지도 영역)
                    - 상세 위치: Travelproduct의 travelproductAddress 정보 활용
