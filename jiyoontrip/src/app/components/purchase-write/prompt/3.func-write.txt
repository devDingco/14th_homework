핵심요구사항)
            1) 폼 검증 기능 구현
                1-1) Zod 스키마 정의
                    - schema.ts 파일에 zod 스키마를 정의할 것
                    - CreateTravelproductInput 타입을 참고하여 스키마 작성
                    - 필수 필드 검증:
                        - name: string, 최소 1자 이상
                        - remarks: string, 최소 1자 이상
                        - contents: string, 최소 1자 이상
                        - price: number, 양수 값
                    - 선택 필드:
                        - tags: string[] (배열 형태로 처리)
                        - travelproductAddress: TravelproductAddressInput (주소 정보)
                        - images: string[] (이미지 URL 배열)
                
                1-2) react-hook-form 연동
                    - zodResolver를 사용하여 zod 스키마와 react-hook-form 연동
                    - mode: "onChange" 설정
                    - 각 입력 필드에 register 적용
                    - formState를 통해 폼 유효성 상태 관리

            2) GraphQL 뮤테이션 구현
                2-1) createTravelproduct 뮤테이션 정의
                    - queries.ts 파일에 GraphQL 뮤테이션 정의
                    - 뮤테이션명: createTravelproduct
                    - 입력 변수: $createTravelproductInput: CreateTravelproductInput!
                    - 반환 필드:
                        - _id
                        - name
                        - remarks
                        - contents
                        - price
                        - tags
                        - images
                        - travelproductAddress (zipcode, address, addressDetail, lat, lng)
                        - seller
                        - createdAt
                        - updatedAt
                
                2-2) @tanstack/react-query를 사용한 뮤테이션 처리
                    - hooks/index.write.hook.ts에 useMutation 훅 구현
                    - 성공 시: 등록된 상품 상세 페이지로 이동
                    - 실패 시: 에러 메시지 표시
                    - 로딩 상태 관리

            3) 폼 필드 바인딩
                3-1) 기본 필드 바인딩
                    - 상품명 (name): MyInput 컴포넌트 사용
                    - 한줄 요약 (remarks): MyInput 컴포넌트 사용
                    - 상품 설명 (contents): SunEditor 컴포넌트 사용
                    - 판매 가격 (price): MyInput 컴포넌트 사용, 숫자만 입력 가능하도록 처리
                    - 태그 입력 (tags): MyInput 컴포넌트 사용, 쉼표 또는 공백으로 구분하여 배열로 변환
                
                3-2) 주소 필드 바인딩
                    - 우편번호 (zipcode): MyInput 컴포넌트 사용

                    - 상세주소 (addressDetail): MyInput 컴포넌트 사용 (필요시)
                    - 위도 (lat): MyInput 컴포넌트 사용, 주소 검색 후 자동 입력

                    - 주소 검색 완료 후 위도/경도 자동 설정
                    - 지도에 마커 표시 (위도/경도가 있을 경우)
